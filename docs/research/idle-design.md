# Topic: idle-design

## Summary

Idle/incremental economy design has a stable canonical math core that has not changed since Kongregate's Anthony Pecorella documented it in 2015-2017, and the 2025-2026 sources mostly refine benchmarks rather than mechanics. Generators cost cost_base * r^owned with r typically 1.07 (AdVenture Capitalist lemonade) to 1.15 (Cookie Clicker buildings); production is base * owned * multipliers, so exponential costs versus linear production create deliberate 'walls' that act as a natural energy system. Milestone multipliers (x2 profit at 25 and 50 owned in AdCap; 25/50/100 'speed doublers') create 'bumps' of rapid purchases and keep older generators relevant. Prestige converts exponential growth back to a linear ladder; the exponent of the prestige-currency formula sets run length: square-root formulas (AdCap angels = 150*sqrt(lifetime/1e15), Realm Grinder) need ~4x earnings to double, Cookie Clicker's cube root (floor(cbrt(lifetime/1e12)), +1% CpS per level) needs ~8x, and Egg Inc's ~1/7 exponent needs ~128x, which pushes players toward repeated short runs. Layered games (Antimatter Dimensions) gate each new layer at the IEEE-754 double limit 1.8e308 and give roughly x10 (IP) or x5 (EP) per additional 1e308, which is the reason break_infinity.js (mantissa*10^exponent, up to 1e(9e15), 50-600x faster than decimal.js) and break_eternity.js (sign/layer/mag, up to 10^^1e308) exist. Offline caps cluster at 2-24h: Egg Inc ~2h (2017), MergeCiv 12h, Melvor and Tideward 24h (Melvor started at 12h; cap justified by both daily-login retention and on-device replay cost of ~30,000 actions per 24h), Idle Miner Tycoon caps by warehouse value rather than time, Clicker Heroes has no strict cap.

Benchmarks: GameAnalytics' Aug 2026 report gives mobile medians D1 ~22% / D7 ~4% / D30 ~0.75%, ~3.9 sessions/day of ~3.3 min, with no genre cut; other 2026 aggregators put medians at 26/10/3-4 and simulation at 30/8.7/3. Idle developers report much higher D1 (Kolibri 63-81%, AdCap ~60% D1 / ~50% D7 on web in 2015). Kolibri's Idle Miner Tycoon earns ~60% from ads with ~8 rewarded ads per player per day and ~9.5-10 min sessions; Appodeal measured 73 rewarded videos per idle user over Jun 2024-Jan 2025. 2026 US rewarded-video eCPMs are ~$16.5 Android / ~$19.6 iOS (tier-1 casual $12-25, tier-2 $6-14, tier-3 $1-5; Q4 +30-50%), completion ~95%. Payer conversion is 1.8% globally with 2-5% as a common target; historical idle web titles hit 3-10%. Ad-frequency consensus: first interstitial only after 60-90s, 1-2 interstitials per session (hard cap 4-6, 2-3 min apart; >3 per session costs 20-30% D7), 2-6 rewarded views per DAU with 40-70% opt-in.

Monetization patterns that hold up: permanent x3 multipliers early, cash infusions as a % of current rate, instant prestige, rewarded 2x/time-skip boosts, ad-removal subscriptions ($0.99/7 days, $3.99/30 days in Cats & Soup), and $9.99 monthly battle passes tied to event content (Idle Miner Tycoon; critics called it 'tacked on'). Event content is the strongest LiveOps lever (event mines often doubled weekend revenue; AdCap only got events after adding a PlayFab backend post-launch).

Anti-cheat: device wall-clock is user-editable; Android elapsedRealtime (monotonic since boot, counts deep sleep) plus server timestamps are the standard defenses, but Unity explicitly warns that server time alone does not stop modified clients, so state-affecting rewards need server-side sanity checks (affordability, rate limits, plausible progress per elapsed second). No public idle-specific case study of deterministic replay validation was found; the inference from Tideward's ~30k actions/24h is that server-side replay of an input log is cheap enough for idle games.

## Findings (34)

1. **[high]** Canonical generator formulas: cost_next = cost_base * rate_growth^owned; production_total = (production_base * owned) * multipliers. AdVenture Capitalist lemonade stand uses growth 1.07, base cost 4 (3.738), base production 1.67/sec, with x2 multipliers at 25 and 50 owned. Bulk-buy cost = b*r^k*(r^n-1)/(r-1); max affordable n = floor(log_r(c*(r-1)/(b*r^k) + 1)).
   - Source: https://www.gamedeveloper.com/design/the-math-of-idle-games-part-i (2016-10-13)
   - Relevance: These are the exact formulas and reference constants the spec's economy layer should implement and tune.

2. **[high]** Cookie Clicker building price = base * 1.15^(owned - free); base cost/CpS: Cursor 15/0.1, Grandma 100/1, Farm 1,100/8, Mine 12,000/47, Factory 130,000/260; buy-10 multiplier 20.3037; sell refund 25% of current price; prices eventually hit the 2^1024 double-precision limit.
   - Source: https://cookieclicker.wiki.gg/wiki/Buildings (2026 (live wiki; consistent with Dinogame 2025 summary))
   - Relevance: Gives a proven r=1.15 tier ladder and a concrete base-cost/CpS ratio (~10x cost per ~5-8x output) to copy for tier spacing.

3. **[high]** Cookie Clicker prestige = floor(cbrt(lifetime cookies baked / 1e12)); heavenly chips gained 1:1 with prestige levels; each prestige level grants +1% CpS (additive) once the heavenly upgrade is bought; doubling prestige requires ~8x lifetime cookies. First recommended ascension ~365 chips (~48.6 quintillion cookies).
   - Source: https://cookieclicker.wiki.gg/wiki/Heavenly_Chips (2026 (live wiki); formula also in Pecorella Part III 2017-02-01)
   - Relevance: Cube-root prestige is the 'slow, long runs' reference point; the +1%/level additive bonus is a safe default reset reward.

4. **[high]** AdVenture Capitalist angels = 150 * sqrt(lifetime earnings / 1e15) minus angels already claimed; each angel gives +2% profit (50 angels = x2); doubling angel count needs roughly 3-4x earnings; lifetime-based formulas let players reset repeatedly at the same point with diminishing gains.
   - Source: https://steamcommunity.com/app/346900/discussions/0/620712999971234569/ (Steam thread (undated, ~2015); formula corroborated by Pecorella Part III 2017-02-01)
   - Relevance: Square-root prestige with a linear +2%/unit bonus is the 'fast, frequent resets' reference; the 150 constant sets first-reset timing.

5. **[high]** Prestige exponent sets run length: square-root formulas (AdCap, Realm Grinder p = (sqrt(1 + 8*c_M/1e12) - 1)/2) need ~4x earnings to double prestige; cube root (Cookie Clicker) ~8x; Egg Inc's delta_p = (c_R/1e6)^0.14 needs ~128x. Run-based formulas (Egg Inc, Clicker Heroes) produce flat reward curves that encourage repeated resets at the same stage; Egg Inc capped offline at 2 hours (2017) so progress moves in 'staircase tiers' via multiplier milestones.
   - Source: https://www.gamedeveloper.com/design/the-math-of-idle-games-part-iii (2017-02-01)
   - Relevance: Lets the spec pick a prestige exponent deliberately for a target run length instead of copying one game.

6. **[medium]** Derivative Clicker models generators that produce lower-tier generators: costs like 5 * 1.1^n; tiered production follows 1, x, x^2/2, x^3/6 ... x^n/n! (approaching e^x); each purchased tier-1 building boosts all tier-1 production by 0.05% to keep low tiers relevant.
   - Source: https://www.gamedeveloper.com/game-platforms/the-math-of-idle-games-part-ii (2016-12-14)
   - Relevance: Polynomial-toward-exponential pacing alternative to pure r^n costs; the 0.05% self-boost is a cheap generator-relevance fix.

7. **[high]** Pecorella GDC 2015 design takeaways: exponential cost/reward growth is 'a natural energy system without an energy currency'; prestige is 'ladder climbing' that turns exponential growth back to linear; core loop is 'log in, spend all your cash, log out, return in a few hours'; 'Make it bumpy - smooth curves are boring'; regular updates are 'true for every successful idle game'; ads kept 'relatively scarce' keep tolerance high; an early permanent x3 multiplier purchase is 'extremely compelling'.
   - Source: https://archive.org/stream/GDC2015Pecorella/GDC2015-Pecorella_djvu.txt (2015-03 (GDC 2015))
   - Relevance: Foundational public design doc; the wall/bump/prestige principles and ad-scarcity rule map directly onto spec requirements.
